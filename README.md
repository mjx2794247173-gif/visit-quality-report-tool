# 虚假拜访通报工具

一个浏览器本地运行的 Excel 分析工具：上传 CRM 已质检的拜访明细后，可按时间、省区和实际拜访方式筛选，自动汇总重点人员并生成可复制的通报文案。

在线预览（启用 GitHub Pages 后）：

`https://mjx2794247173-gif.github.io/visit-quality-report-tool/`

## 能做什么

- 在浏览器本地读取 `.xlsx` 导出文件，不上传、不长期保存业务数据
- 按表头名称识别数据，不依赖 Excel 固定列顺序
- 支持按日期、省区、微信／电话／上门筛选
- 将 `质检问题类型` 作为唯一事实来源；工具不自行判断拜访真假
- 过滤“反馈内容无意义”这一不纳入通报的质检项
- 按人员在所选范围内的虚假拜访数量、问题类型数、持续天数、涉及客户数进行阶梯评分并排序
- 每个省区自动展示优先级最高的 3 个案例，生成可直接复制的通报内容
- 提供完全虚构的示例数据，方便体验页面而不使用真实业务数据

## 使用方法

1. 打开网页，点击“选择文件”并导入 CRM 导出的 `.xlsx` 明细；也可以点击“使用示例数据”体验。
2. 设置日期、省区和实际拜访方式。
3. 查看候选案例与评分拆分，确认需要通报的人员。
4. 在“通报预览”中复制全文，按实际业务场景补充或调整后发送。

## 文件字段

工具通过列名映射字段。建议导出文件包含以下列：

| 用途 | 字段名 |
| --- | --- |
| 拜访唯一标识 | `拜访编码` |
| 客户 | `客户编码`、`客户名称` |
| 人员 | `拜访人ERP` |
| 省区 | `拜访人主导省区` |
| 时间 | `实际拜访时间` |
| 拜访方式 | `实际拜访方式` |
| 质检结果 | `质检问题类型` |

## 数据与隐私

页面为纯静态网页。Excel 文件仅在当前浏览器中解析，用于本次计算；工具不会把文件上传到服务器，也不会在本地长期保存。仓库和示例数据均不包含真实业务数据。

## 本地运行

下载或克隆仓库后，直接用现代浏览器打开 `index.html` 即可。页面依赖公开的 JSZip 脚本来读取 `.xlsx` 文件，因此首次使用时需保持网络可用。

## 维护说明

`skill/` 保存了这个工具的产品口径与维护规范：字段解析、筛选口径、评分阶梯、通报文案和界面要求。它用于帮助 AI 或协作者在后续修改时保持现有逻辑一致，不包含真实导出数据。
