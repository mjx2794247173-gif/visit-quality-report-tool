# 统计口径

- “问题最多”默认按该问题类型对应的拜访条数统计，不按文字出现次数计算。
- `反馈内容无意义`永远不参与问题计数、站长候选、评分、排名、摘要或模型上下文。
- 同一站长的多类问题按去重后的质检问题类型统计。
- “连续多天”按实际拜访日期去重后判断连续自然日。
- “重复客户”按同一客户对应多个不同拜访编码统计。
- 省区摘要中的记录数、问题排名和站长列表必须使用同一省区范围，不能用全国总数冒充省区数据。
- “上海”“上海省”“上海省区”等名称需要统一归一化后再筛选。
- 重点站长排序和评分口径沿用现有通报规则，模型只能解释已有结果，不能创造新规则。

常用字段包括：拜访编码、拜访人 ERP、拜访人主导省区、实际拜访时间、客户编码/客户名称、实际拜访方式、质检问题类型。
