# 京ME机器人接入 SOP

本文同时面向普通使用者和 Agent/开发者。只使用占位符，不包含真实密钥、群号、ERP、内部 URL 或业务数据。

## 一、普通使用者

### 1. 检查并安装工具

打开 PowerShell：

```powershell
o2 --help
```

如果提示找不到命令，应通过公司批准的软件中心或 Oxygen 安装渠道安装，不要从不明网站下载 `o2.exe`。

安装后登录并检查京ME工具：

```powershell
o2 login
o2 search jdme
o2 info jdme
o2 install jdme
o2 skill jdme
```

如果 `o2 info jdme` 找不到工具，通常是账号、网络或注册表权限问题，应联系内部工具维护人。

### 2. 创建机器人

京ME开放平台菜单可能变化，通用流程是：

1. 打开京ME开放平台或机器人管理入口；
2. 新建机器人应用，填写名称和用途；
3. 开启消息发送权限；
4. 创建或选择测试群；
5. 将机器人加入测试群；
6. 完成管理员审批或发布；
7. 回到 `o2/jdme` 完成认证。

### 3. 配置本机

真实配置只放在本机或 `o2` 的认证状态中：

```dotenv
JINGME_ENABLED=true
JINGME_DEFAULT_ROBOT_ID=<本机机器人ID>
JINGME_GROUP_ID=<本机测试群ID>
```

首次使用必须先做 Dry Run 或测试群发送。真实发送前必须展示预览并获得用户二次确认。

## 二、Agent/开发者

### 1. 启动检查

Agent 应依次检查：

```text
o2 是否存在 → jdme 是否注册 → 认证是否有效 → 机器人是否有发送权限 → 目标群是否包含机器人
```

建议返回：`未安装`、`未配置`、`可发送` 三种状态。不能向前端返回 App Secret、Token、内部 URL 或完整群 ID。

### 2. 白名单调用

只允许调用登记过的能力：

```text
message.send-text
group.list
group.member-list
```

Agent 不得执行任意 Shell，不得自行改权限、加成员、创建群、选择任意目标，也不得在用户确认前发送。

### 3. 发送参数

```json
{
  "content": "已确认的通报内容",
  "erp": "可选：ERP目标",
  "group_id": "可选：群目标",
  "confirmed": true,
  "dry_run": false
}
```

约束：`erp` 和 `group_id` 二选一；`confirmed` 必须为 `true`；内容必须来自当前会话已经展示的预览；内容要经过长度限制；不发送原始 Excel 行、照片判断或未经校验的模型数字。

### 4. 推荐状态机

```text
用户请求发送 → 读取已校验结果 → 生成预览 → 展示目标和正文 → 用户确认 → 校验目标 → 调用白名单工具 → 返回结果
```

用户修改预览后必须重新展示并再次确认，不能静默替换已确认内容。

### 5. 错误处理

| 情况 | 处理 |
|---|---|
| 找不到 `o2` | 引导安装，不重试发送 |
| 找不到 `jdme` | 检查 `o2 info jdme` |
| 未登录 | 引导 `o2 login` |
| 目标无权限 | 联系管理员，不修改目标 |
| 未确认 | 回到预览，不发送 |
| 内容过长 | 按规则拆分或缩短 |
| 重复发送 | 阻止副作用并提示 |

失败不能伪装成成功，也不能无限自动重试。

## 三、安全边界

公开仓库可以包含适配器抽象、参数校验、Mock/Dry-run、脱敏配置和本文档；不能包含：

- 真实 App Key、App Secret、Token；
- 真实机器人 ID、群 ID、ERP 映射；
- 内部域名、接口地址和认证配置；
- CRM 原始 Excel、真实发送日志和本机 `o2` 配置目录。

如果凭证曾经提交过，即使后来删除文件，也必须立即吊销并重新生成。

## 四、验收清单

### 普通使用者

- [ ] `o2 --help` 可用；
- [ ] `o2 info jdme` 可用；
- [ ] 已完成认证；
- [ ] 机器人有发送权限并已加入测试群；
- [ ] Dry Run 成功；
- [ ] 真实发送前有预览和确认；
- [ ] 失败时能看到原因。

### Agent/开发者

- [ ] 凭证不在代码和 Git 历史中；
- [ ] 只调用白名单工具；
- [ ] ERP 与群目标严格二选一；
- [ ] 未确认不会发送；
- [ ] 内容来自当前确认预览；
- [ ] 重复发送会被阻止；
- [ ] 日志不记录正文、密钥和完整目标；
- [ ] 仓库不含真实业务数据。
